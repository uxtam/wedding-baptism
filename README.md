# Wedding & Baptism Weekend

Mobile-friendly itinerary page for November 19–21, 2026 in Houston, Texas.

Single static file: `index.html` (no build step, no dependencies besides Google Fonts).

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example `wedding-weekend`). Public is required for free Pages on personal accounts.
2. Upload `index.html` and `README.md` to the repository root (Add file → Upload files).
3. Go to Settings → Pages. Under "Build and deployment", set Source to "Deploy from a branch", choose the `main` branch and the `/ (root)` folder, then Save.
4. After a minute or two the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Editing later

Open `index.html` on GitHub and click the pencil icon. Times, addresses and notes are plain text in the HTML. Commit the change and the site updates within a minute or two.
